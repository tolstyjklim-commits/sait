# WoodyArt — магазин деревянного декора

Сайт для продажи деревянных изделий (панно, карты мира, часы, полки) с интеграцией платежной системы **RollyPay**.

## Структура
- `index.html` — главная страница с каталогом и формой оформления заказа
- `success.html` — страница после успешной оплаты
- `style.css` — стили
- `app.js` — каталог, корзина, оформление заказа через RollyPay

## RollyPay
Оплата реализована в `app.js` — запрос к `https://api.rollypay.example/v1/checkout` создаёт платежную сессию и перенаправляет покупателя на `data.payment_url`.  
Замените URL на реальный endpoint RollyPay и добавьте свои API-ключи перед запуском в продакшене.

## Размещение на GitHub Pages
1. Создайте репозиторий на GitHub.
2. Загрузите файлы в репозиторий.
3. В настройках репозитория (Settings → Pages) укажите ветку `main` и папку `/ (root)`.
4. Сайт будет доступен по адресу `https://<ваш-логин>.github.io/wooden-art-store/`.

## Разработка
Откройте `index.html` в браузере. Для RollyPay требуется интернет и действующий API-ключ.
